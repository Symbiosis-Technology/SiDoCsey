WHY

为什么要做这个项目

市面上已有的方案，总是差最后一步。SiDoCsey 把这些缺口一次补齐。

原版 Shizuku 只给了“权限”，没给“结果”

原版 Shizuku 授权后，静默安装、卸载、执行 shell 命令这些能力要你自己再搭工具。授权和应用之间隔着一层，体验是断裂的。

普通安装器“静默”不够彻底

要么每次安装都要弹系统确认框，要么要求 Root。SiDoCsey 以 shell 身份执行 pm 命令，安装、卸载、打桌面全程无弹窗、无打扰。

工具应该是“一体”的

配对一个管理端、再装一个终端、再找一个授权工具——不应该。一个 SiDoCsey：配对、服务、终端、授权、模块、桌面，全在一处。

FAQ

常见问题

需要 Root 吗？
不需要。SiDoCsey 通过无线调试配对，以 shell 身份（uid=2000）执行 pm 命令，与 Shizuku 同一权限模型。
和原版 Shizuku 是什么关系？会冲突吗？
不依赖、不冲突。内置服务独立实现；若手机上已装原版 Shizuku 并授权，安装卸载会自动复用其通道。两者可并存。
为什么有时候提示“无线调试”？
首次使用或内置服务未启动时，需要无线调试作为 shell 通道。在开发者选项开启“无线调试”，在应用内通知栏配对一次即可。
包名为什么是小写 sidoscey.app？
Android 包名只允许小写字母。按要求落地为 sidoscey.app，应用名仍显示为 SiDoCsey。
静默安装会被系统拦截吗？
需要开启无线调试（shell 通道）。个别厂商 ROM 的安装策略可能限制特定安装选项，可在应用内调整“替换 / 测试包 / 降级 / 授权”等选项。
源码可以自己编译吗？
可以。源码包内含完整 Android 工程（AGP 8.10.1 / Gradle 8.11.1 / compileSdk 36），按说明导入 Android Studio 即可构建。
使用是否安全？
能力完全本地执行，不联网上传任何数据；源码开放可审计。请仅用于你拥有权限的设备与合法用途。
